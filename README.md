# Serverledge Simulator

Simulatore Python della piattaforma serverless Serverledge per lo studio delle politiche di autoscaling.

`./run.sh` avvia lo scenario di esempio per cinque arrivi nell'ambiente Conda
`serverledge-simulator`. Per scegliere scenario e numero di arrivi, usa
`./run.sh examples/scenarios/startup.toml --arrivals 10`.
